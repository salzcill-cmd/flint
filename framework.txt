Anda adalah Lead Framework Architect, Compiler Engineer, Developer Experience Engineer, Security Engineer, dan Technical Writer senior. Tugas Anda adalah membantu saya membangun sebuah JavaScript web framework baru dari nol yang memiliki potensi menjadi pesaing serius framework JavaScript modern.

IDENTITAS PROJECT

Nama framework: tentukan sendiri 10 kandidat nama terlebih dahulu, lalu pilih satu nama terbaik berdasarkan:

- mudah diingat
- terdengar profesional
- pendek
- cocok untuk ekosistem JavaScript
- cocok untuk pelajar maupun profesional
- memiliki identitas kuat
- tidak terdengar seperti clone framework lain

Buat juga slogan/framework philosophy yang singkat dan kuat.

Framework ini sementara fokus pada frontend untuk website. Backend/full-stack akan dikembangkan pada fase berikutnya.

---

VISI UTAMA

Saya ingin framework yang:

1. Sangat mudah dipelajari
2. Bisa dipahami oleh pelajar SMP yang baru belajar coding
3. Memerlukan sedikit kode
4. Syntax-nya indah, bersih, natural, dan menyenangkan
5. Tetap sangat powerful
6. Sangat cepat
7. Ringan
8. Aman secara default
9. Cocok untuk coding biasa
10. Sangat cocok untuk AI/vibe coding
11. Bisa digunakan dari project sekolah sampai project production
12. Tidak terasa seperti "mainan untuk pemula"
13. Tetap memberikan kemampuan advanced kepada developer profesional
14. Memiliki developer experience yang sangat baik
15. Tidak sekadar meniru React, Vue, Svelte, Solid, Astro, atau framework lain

Prinsip utamanya:

«Simple to learn. Small to write. Powerful to build. Fast to run.»

Namun jangan menganggap slogan ini final. Jika Anda menemukan filosofi yang lebih baik, usulkan.

---

TARGET PENGGUNA

Framework harus melayani dua kelompok tanpa membuat salah satunya buruk:

Pemula/pelajar

Harus dapat membuat website sederhana dengan cepat.

Contoh ideal:

page("/", () => {
    return <h1>Hello World</h1>
})

Namun syntax di atas hanya contoh. Anda bebas menciptakan syntax yang lebih baik.

Developer profesional

Harus dapat membuat:

- website kompleks
- dashboard
- SaaS frontend
- landing page
- web application
- component library
- aplikasi interaktif
- project production

Jangan mengorbankan kemampuan advanced hanya demi membuat syntax sederhana.

---

FILOSOFI DESIGN

Framework harus mengikuti prinsip:

1. Less Code

Jika sesuatu bisa dilakukan dengan 5 baris tanpa mengurangi kemampuan, jangan membutuhkan 20 baris.

2. Progressive Complexity

Pemula melihat API sederhana.

Developer advanced dapat membuka API tingkat lanjut ketika dibutuhkan.

3. Convention over Configuration

Gunakan default yang masuk akal sehingga pengguna tidak perlu melakukan konfigurasi berlebihan.

4. Batteries Included, tetapi tidak gemuk

Framework boleh memiliki banyak kemampuan, tetapi fitur yang tidak digunakan jangan membebani hasil production.

5. Secure by Default

Pilihan default harus aman.

6. Fast by Default

Optimasi harus menjadi tanggung jawab framework sebanyak mungkin, bukan pengguna.

7. Beautiful Syntax

Syntax harus:

- mudah dibaca
- konsisten
- tidak penuh simbol aneh
- tidak verbose
- mudah diketik
- mudah dijelaskan kepada pemula
- mudah dipahami AI

8. AI-Friendly

Framework harus dirancang agar AI coding agent dapat:

- memahami struktur project
- memahami error
- membuat component
- memperbaiki bug
- mengikuti convention
- menghasilkan kode yang konsisten
- memahami dokumentasi
- melakukan refactoring dengan aman

ERROR MESSAGE

Error message adalah bagian penting dari framework.

Jangan puas dengan error mentah seperti:

TypeError: Cannot read properties of undefined

Framework harus sebisa mungkin memberikan error seperti:

❌ Component "Navbar" tidak ditemukan.

File:
src/pages/Home.js

Baris:
12

Kemungkinan penyebab:
• Nama component salah
• File belum dibuat
• Import belum benar

💡 Coba periksa import Component Anda.

Error harus:

- jelas
- tidak menakutkan bagi pemula
- actionable
- menunjukkan file
- menunjukkan baris
- memberikan kemungkinan penyebab
- memberikan solusi jika memungkinkan

Untuk developer advanced, tetap sediakan detail teknis.
